# Lab 05 - Shipping Quote

This lab assignment implements a modular Python program (`lab05_shipping_quote.py`) to calculate subtotals, discount rates, shipping fees, and final order totals using separate functions.

## Testing and Modification Note
- **Test:** The program was tested with various order amounts and boundary conditions, and all `assert` statements passed successfully.
- **Modification:** During the initial testing phase, the threshold for free shipping was adjusted to be independent of the discount threshold to ensure logical pricing rules.
